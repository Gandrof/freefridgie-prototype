# FreeFridgie: інтерактивний AI-прототип

Один файл `index.html` без залежностей (шрифт Nunito підтягується з Google Fonts; без інтернету працює зі шрифтом системи).

## Запуск
Просто відкрийте `index.html` у браузері. На комп'ютері застосунок показується в рамці телефона, на телефоні займає весь екран.

## Публікація на GitHub Pages
1. Покладіть `index.html` у корінь репозиторію (або в папку `docs/`).
2. Settings → Pages → Source: `main` / `/ (root)` (або `/docs`) → Save.
3. Посилання: `https://<користувач>.github.io/<репозиторій>/`.

## Що вміє
- Сценарій 1: «+» → «Сфотографувати» (імітація розпізнавання) → перевірка даних → «Підтвердити» → продукт на полиці.
- Гілки: збій розпізнавання, «Без камери», ручне додавання, скасування, переповнені полиці, порожній холодильник.
- Полиці й картки (кнопка «Вигляд»), вибір продукту, переміщення ↑ ↓ або тапом на порожній слот, деталі, видалення з підтвердженням.
- Поради: що посунути (прийняти / відхилити), що приготувати (бракує 1–2 інгредієнтів), порада дня.
- Налаштування: світла / темна / авто тема, нагадування, демо-режим розпізнавання, тестове push-сповіщення, скидання даних.
- Стан зберігається в localStorage; якщо сховище недоступне, застосунок працює без збереження.

## Захист від «ламання»
Екранування HTML у назвах, обмеження 40 символів, маска і перевірка дати, блокування подвійних натискань під час розпізнавання, кнопка «Зберегти» неактивна до коректних даних, Esc закриває діалоги, видимий фокус, зони дотику не менше 44 px.

Розпізнавання фото в прототипі змодельоване (мок); це треба прямо казати на захисті.
